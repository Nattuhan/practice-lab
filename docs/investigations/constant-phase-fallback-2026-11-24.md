# 音源と一定テンポの位相が合わない場合の再解析

## 再現

「DISCO FLIGHT」の原曲では、元音源のモデル出力で冒頭に約0.48〜0.49秒の拍が続いた。後方の約0.44秒で揃えたグリッドを前方へ伸ばしても、この間隔の差で拍の位置がずれる。ドラム音源の34.808秒の打点は、以前の一定クリックから約220ミリ秒、モデルが検出した拍から約2ミリ秒の位置にあった。20〜44秒の強いドラム打点57個で、最寄りの拍までの誤差の中央値は一定クリックの126ミリ秒に対して検出拍では10ミリ秒だった。

原曲全体のモデル出力と残り2件の冒頭43秒の出力を以前の全曲グリッドに重ね、3件で一定クリックと検出拍が継続して離れる区間を確認した。曲名と時刻は再現記録に限る。

## 判定と処理

一定テンポの候補を作ってから、検出拍と固定拍が1拍の20%より離れ、フレームごとの拍確率が検出拍側に明確に寄る箇所を数える。12拍ずつの隣り合う両区間で証拠が繰り返し得られる場合に可変テンポへ切り替える。固定拍や小節頭の配置自体が成立しない場合も、検出拍で再生できれば切り替える。孤立したフィルや短い誤検出を理由に曲全体を切り替えない。

フォールバックでは同じ推論の検出時刻から可変テンポ処理を行う。固定用の整形済み拍列は引き継がない。実際のモードを保存し、再解析の初期選択とキャッシュ判定にはユーザーが指定した優先モードを使う。

可変テンポのベースイントロでは、直後の短い拍列と連続する小節頭から局所の周期・位相・拍子を求める。持続する低音が始まる位置と、休符を挟む低音の打点がその細分拍に合う場合に、最初の検出拍までの欠落を埋める。後方にある別のテンポと拍の位相を冒頭に適用しない。

## 回帰検証

- 別の周期と拍子を持つ合成音源で、ベースの冒頭を補い、曲中の実際のテンポ変化と小節頭を保持した。直後の拍と合わない低音からは補完しない。
- 同じ拍検出を使い、継続した音源証拠でだけフォールバックすることと、短いフィルで一定テンポを維持することを確認した。
- 保存済み音声からの再解析では、実際に使う拍時刻と、以前に選んだ「一定テンポを優先」の両方を保持する。
