# PracticeLab 利用者ガイド

## 曲を追加する

画面上部の「新しい解析」を押し、YouTube URLを貼り付けるか、WAV、M4A、MP3、FLAC、AAC、OGGファイルを選びます。

動画全体だけでなく、開始時間と終了時間を指定した区間解析もできます。区間解析は元の曲とは別のセッションとして保存されます。

時間は`3`なら3秒、`1:30`なら1分30秒として入力します。処理一覧にはYouTubeの内部IDではなく、取得できた曲名を表示します。

曲構成のAI解析は、曲の長さと端末性能によって数分以上かかります。解析ライブラリから正確な進捗率が得られない区間では経過時間を表示します。処理が動いている限り、途中ログが出ないことだけを理由に終了しません。全体の安全上限は30分で、利用者はいつでもキャンセルできます。

アプリ終了時に実行中だった処理は、次回起動時に「再開待ち」として処理一覧へ表示されます。「再開」で続けるか、「キャンセル」で再開情報を破棄できます。キャンセルした処理は次回起動時に再表示されません。複数ある場合は「すべてキャンセル」も使用できます。

## 練習する

解析が完了した曲は左側のライブラリへ追加されます。

- 再生・一時停止: 画面の再生ボタン、またはスペースキー
- 移動: セクションまたは波形をクリック
- 区間ループ: セクションを選ぶか、波形上をドラッグ
- 速度変更: プレイヤーの速度スライダー
- クリック: クリックボタンを有効化。設定画面の「一般」→「再生」で「標準」「ウッド」「ハイハット」から音色を選択可能。「標準」は低め・標準・高めの音程も選択できます。選択は次回起動時も保持され、クリックを含むパート書き出しにも反映
- BPM補正: BPM欄の「半分」「2倍」「元に戻す」を使用。変更後の値は「保存」で曲ごとに保持
- 動画の全画面表示: PCでは動画をダブルクリックするか、動画右下の全画面ボタンを使用。`Esc`で終了

曲を開くと最終閲覧日時が更新されます。再生しなくても「最後に開いた順」の並べ替えに反映されます。練習回数は記録しません。

波形をドラッグしている間は動画だけが追従し、音声は操作位置が確定してから再生します。通常再生中のパートは連続して再生し、再生開始、明示的な移動、ループ時に同じ時刻へそろえます。

PCの全画面表示では、再生操作、楽曲・クリック音量、BPM補正、再生速度を上部の1行にまとめ、波形、現在時刻、総時間、ループ情報を下部の1段にまとめて表示します。通常画面は各操作を見やすい2段で表示します。タッチ端末では、動画の左右をダブルタップすると5秒ずつ移動します。

## ライブラリを整理する

左側の検索欄で曲名とタグを検索できます。最後に開いた順、追加順、曲名順、フォルダー順への並べ替えに対応し、選んだ並び順を保持します。フォルダーを作成して曲を整理することもできます。

## 曲構成を直す

曲構成の「編集」から、解析されたセクションを分割・結合・名称変更できます。編集後も、自動解析結果へ戻せます。

## パート分離

右側のパート分離パネルから、ボーカル、ドラム、ベース、その他を生成します。生成後は各パートの音量、ミュート、ソロ、強調を操作できます。

全パートをミュートすると元音源も鳴らず、クリックだけで練習できます。パートの読み込み・再生に失敗した場合は元音源へ戻り、失敗したパート名と「パートを再試行」を表示します。「元音源を使用」を選ぶとパートの自動復帰を止められます。読み込み待ちから復帰する場合は、現在の位置と再生速度へ全パートをそろえます。

パートの再生成では、新しい4パートの変換が完了してから入れ替えます。失敗・キャンセル時も以前の再生用パート音源を保持します。

現在のミックスはMP3として書き出せます。選択区間だけを書き出すこともできます。

## 楽譜を抽出する

楽譜抽出は任意の追加機能です。設定の「追加機能」から楽譜抽出機能を追加すると「楽譜抽出」タブが表示されます。動画内の楽譜領域を指定し、重複する画面を除きながら画像化できます。出力形式はA4、A3見開き、縦長PNGから選択できます。使わなくなった場合は同じ画面から追加機能だけを削除でき、保存済みの曲や成果物は残ります。

## 保存済みの曲を再解析する

曲を開き「この曲を再解析」から「保存済み音声で再解析」を選ぶと、ダウンロードや音声・動画の変換をせず、BPM・拍・小節・曲構成を更新します。これが標準の選択です。手元から追加した音声にも使えます。パート別音源と楽譜は再生成しません。手動編集したBPM・曲構成は新しい解析結果に置き換わります。

保存済み音声は元の解析範囲のまま使用します。YouTubeの取得し直しや範囲変更が必要な場合は「元動画を再取得して再解析」を選んでください。保存済みの元音声がない場合は理由を表示し、自動で再取得はしません。解析の失敗・キャンセルでは以前の解析結果を残します。

## 処理履歴を見る

画面上部の設定を開き、「処理履歴」から曲構成の解析、パート分離、パート書き出し、楽譜処理、端末間同期を確認できます。

各行には曲名、開始日時、所要時間、成功・失敗・キャンセル・処理中の状態が表示されます。履歴は端末内に最大200件保存されます。同じ曲を再解析しても以前の記録は残ります。

画面右下の処理一覧は、ヘッダーの「−」で小さなバッジへ最小化できます。バッジの上向き矢印で再表示できます。最小化しても処理は続き、処理履歴や結果は削除されません。

処理履歴はデスクトップ版だけの機能です。R2静的閲覧版には表示されず、R2へアップロードされません。

## 別端末と同期する

設定画面の「クラウド連携」から、自分のCloudflare R2バケットを接続できます。接続後は上部の「端末間同期」で、解析済みの曲を自分の端末間で同期できます。

接続情報を別端末へ渡す場合は、暗号化接続ファイルと復号コードを別々の経路で転送してください。

## 容量を整理する

設定画面の「ストレージ」では、再生成できる作業キャッシュ、画面・動画キャッシュ、ログ、解析モデルを整理できます。元動画と再生用動画が同じ内容ならハードリンク化して重複容量を減らし、ライブラリに存在しない孤立ファイルも候補として表示します。

通常のキャッシュ整理では、元音声、動画、パート、解析結果、楽譜成果物を削除しません。孤立ファイルの整理を選んだ場合だけ、ライブラリにも解析結果にも紐づかない再生用ファイルを削除します。

再生時の音切れや同期を調べる診断ログも端末内に保存されます。音声データ自体は含まず、自動送信もされません。不要になったログはこの画面から削除できます。

## Windowsの解析環境

WindowsはCPU解析が初期値です。設定の「追加機能」からWindows CPU解析機能を追加すれば、NVIDIA、WSL2、CUDAなしで利用できます。対応するNVIDIA GPUで高速化したい場合だけ、設定の「解析環境」でNVIDIAを選び、セットアップを実行してください。

Macでは設定の「追加機能」からApple Silicon向け解析機能を追加できます。NVIDIA、WSL、CUDAは使用しないため、関連する設定は表示されません。

## デスクトップ版と閲覧版

デスクトップ版は解析・編集・管理を行うアプリです。R2静的閲覧版は、解析済みの曲を再生するための読み取り専用画面です。

閲覧版から解析、履歴表示、設定変更、データ削除はできません。
