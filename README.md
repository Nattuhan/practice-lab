# PracticeLab

曲を解析して、練習しやすい形で再生・整理するデスクトップアプリです。

YouTube URLや手元の音声ファイルから、BPM、拍、小節、曲構成を解析できます。解析後は、速度変更、区間ループ、クリック再生、パート分離を同じ画面で利用できます。動画からの楽譜抽出は必要な人だけ追加できます。

## ダウンロード

[最新バージョンをダウンロード](https://github.com/Nattuhan/practice-lab/releases/latest)

| 使用環境 | ダウンロードするファイル |
|---|---|
| Windows 10/11 | `PracticeLab-Setup-<version>.exe` |
| Apple Silicon Mac | `PracticeLab-<version>-arm64.dmg` |

Intel MacとLinuxは正式サポート対象外です。

## できること

- YouTube URL・音声ファイルから曲構成、BPM、拍、小節を解析
- 音程を変えずに再生速度を変更
- セクション移動、任意区間ループ、クリック再生
- ボーカル、ドラム、ベース、その他のパート分離と音量調整
- 任意の追加機能で、動画内の楽譜を画像・ZIPとして抽出
- 曲名・タグ検索、練習回数、最終練習日時の管理
- 解析、同期、書き出しなどの処理履歴と所要時間の確認
- Cloudflare R2を使った自分の端末間でのライブラリ同期

## 最初の使い方

1. PracticeLabを起動します。
2. 「新しい解析」を押します。
3. YouTube URLを貼り付けるか、音声ファイルを選びます。
4. 「解析を開始」を押します。
5. 完了後、左側のライブラリから曲を選んで練習します。

処理中は画面右下に進捗が表示されます。設定の「処理履歴」から、過去の処理結果と所要時間を確認できます。

AIによる曲構成解析は、曲の長さやCPU・GPU性能によって数分以上かかることがあります。処理中は曲名、処理段階、経過時間を表示し、いつでもキャンセルできます。

詳しい操作は[利用者ガイド](docs/user-guide.md)を参照してください。

## 2つの利用形態

PracticeLabは、役割の異なる2つの画面を明確に分けています。

|  | デスクトップ版 | R2静的閲覧版 |
|---|---|---|
| 解析・再解析 | 可能 | 不可 |
| パート分離・楽譜抽出 | 可能 | 不可 |
| 処理履歴 | 端末内に保存・表示 | 非表示・アップロードしない |
| 設定変更 | 可能 | 不可 |
| 解析済み曲の再生 | 可能 | 可能 |
| 主な用途 | 曲を作成・管理する端末 | 解析済み曲を別端末で見る |

R2静的閲覧版は、公開済みの曲データを読むだけです。デスクトップ版の処理履歴、設定、ログ、認証情報はR2へ公開されません。

## データの保存

曲、解析結果、設定、処理履歴は、アプリ本体とは別の端末内データ領域へ保存されます。アプリを更新しても通常は保持されます。

Cloudflare R2連携は任意です。接続しなければ、データは端末内だけで使用されます。

## 困ったとき

- YouTubeの取得に失敗した場合は、ChromeでYouTubeへログインした状態でもう一度試してください。
- WindowsはCPU解析が初期値です。設定の「追加機能」からCPU解析機能を追加できます。GPUで高速化したい場合だけ「解析環境」でNVIDIAを選択してください。
- Macで初回起動を拒否された場合は、[未署名版の案内](UNSIGNED_DISTRIBUTION.md)を確認してください。
- 容量が増えた場合は、設定画面の「ストレージ」を開いてください。
- 再生中に音切れや遅れを感じる場合は、一度Bluetoothを切って内蔵出力でも確認してください。再生診断ログは端末内のApplication Support領域に保存され、設定の「ストレージ」から削除できます。
